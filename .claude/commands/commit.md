# Proceso de /commit
## Pasos
1. Ejecuta `git status` y `git diff` en paralelo para revisar todos los cambios.
2. Ejecuta `git log --oneline -10` para ver el historial reciente.
3. Analiza los cambios
4. Crea el commit usando el siguiente formato de las directrices:
   - Solo encabezado: `git commit -m "<tipo>(<ámbito>): <asunto>"`
6. Ejecuta `git status` para confirmar que el commit fue exitoso.
